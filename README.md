This dashboard analyzes customer support tickets and provides actionable insights for support managers.

## Features

- Top Issue Categories
- Unresolved Tickets with Reasons
- Product Complaint Analysis
- Ticket Status Distribution
- High Priority Tickets
- Manager Summary

## Tech Stack

- Python
- Streamlit
- Pandas
- Matplotlib
